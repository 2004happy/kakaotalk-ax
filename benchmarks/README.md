# 검증·조사 기록

이 폴더는 각 날짜에 실행했던 구현과 관찰의 기록이다. 최신 API는 프로젝트 README와 AX API를 따른다.
v0.8.0에서는 DB 접근·SQLCipher·계정 키 복구·미디어 다운로드·DB 전송 판정 및 비공식 클라이언트를 제거했다.
아래 과거 DB·LOCO 설명은 당시 조사 근거이며 현재 실행 경로나 재현 지시가 아니다.
개인 계정·방·메시지 원문·인증 정보는 포함하지 않는다.

- [2026-11-03 AX 전용 전환](2026-11-03-ax-only-release.md): v0.8.0 DB 경로 제거와 패키지·MCP·창 상태 확인. 새 전송 없음.
- [2026-11-03 별도 계정 화면 비교](2026-11-03-new-account-comparison.md): v0.7.1 AX 읽기·검색·이전 대화·창 상태 비교. 새 전송 없음.
- [2026-11-03 AX 통합 헬퍼](2026-11-03-accessibility-automation.md): v0.7.0에서 한 번 전송과 중복 방지 포함.
