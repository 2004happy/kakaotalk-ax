# DB 조회 + AX 전송 실측 (2026-11-01)

**후속 확인(2026-11-02):** 사용자가 이 실험 뒤 운영정책 위반에 의한 임시 이용제한이
다시 발생했다고 보고했다. 아래 결과는 전송 동작·처리 시간 검증이며, 계정 제재 없이
사용할 수 있다는 검증이 아니다. DB와 AX 중 원인은 분리하지 못했다.
[재발 조사 기록](2026-11-02-restriction-investigation.md)을 함께 참고한다.

나와의 채팅에서 기본 도구 2건과 AX 헬퍼 2건을 교대로 전송했다. 대화 내용과 전송 결과는 모두
읽기 전용 DB에서 확인했다. 두 방식 모두 열린 본인 채팅창과 빈 입력창에서 시작했으며, 헬퍼의
네이티브 바이너리는 미리 빌드했다. 최초 빌드는 1.861초였다.

| 방식 | 1회 | 2회 | 요청별 업무 호출 |
|---|---:|---:|---:|
| 기본 도구로 단계별 조율 | 26.589초 | 39.286초 | 5회 |
| 헬퍼 단일 MCP 실행 | 3.117초 | 2.122초 | 1회 |

기본 방식은 DB 준비, AX 요소 탐색, 입력, 전송, DB 확인 사이의 에이전트 왕복 시간을 포함한다.
헬퍼 시간은 stdio MCP 시작부터 DB 확인 결과 생성까지이며 첫 헬퍼 실행에서 결과를 가져온 추가
폴링 왕복은 제외한다. 실제 에이전트 도구 호출은 기본 5·6회, 헬퍼 2·1회였고, 각 두 번째/첫 번째
실행의 차이는 실행 도구의 비동기 폴링 때문이다. 호출 수 비교의 5→1은 이 폴링을 제외한 업무 단계 수다.

모델 왕복과 DB 단계를 제외한 기본 방식의 UI 도구 3회 실행 시간 합계도 5.624초·9.928초였다.
헬퍼의 위 3.117초·2.122초는 DB 준비·확인과 MCP 시작까지 포함한다. 비교 범위가 다르므로 같은
작업량의 순수 엔진 벤치마크로 해석하지 않는다.

헬퍼 내부 실행 시간은 1.418초·1.153초였다. 나머지는 Python/stdIO MCP 시작 비용이다.
이는 각 2회 관측이며 통계적 벤치마크가 아니다. 기존 도구와 헬퍼는 내부 구현도 다르므로 모든 차이를
배치 처리 하나의 효과로 해석할 수 없다. 방을 찾아 여는 시간과 다양한 PC 상태·다른 방 전송은 측정하지 않았다.

## 정확성과 오류 복구

- 테스트 메시지 4건 모두 대상 방, 본인 발신, 전체 본문, 양수 logId가 일치하는 DB 기록을 정확히 한 건씩 확인했다.
- 줄바꿈·한국어·이모지가 포함된 본문을 그대로 확인했다.
- 기본 도구의 전송 클릭은 두 번 모두 접근성 오류를 반환했으나, DB에서 실제 전송 기록이 확인됐다.
- 헬퍼의 AXPress도 두 번 모두 -25200을 반환했으나, 재전송 없이 DB 확인으로 완료 처리했다.
- 두 번째 헬퍼 요청을 같은 operation_id로 재호출했을 때 nativeCalls=0, 추가 메시지=0이었다.
- 실제 앱에 임시 초안을 넣고 호출했을 때 existing_draft_preserved로 중단했으며, 본문 변경과 전송은 모두 없었다. 임시 초안은 확인 후 원래의 빈 상태로 복구했다.
- 헬퍼는 메시지 목록 AXTable/AXRow/AXCell을 탐색하지 않고, 입력창과 전송 버튼의 속성만 읽는다.
- 로컬 DB 확인은 상대방 읽음·서버 ACK를 직접 확인한 결과가 아니다.

## 재현

1. 설치 후 대상 채팅창을 열고 입력창을 비운다. 테스트는 본인 채팅으로 한정한다.
2. `.venv/bin/kakaotalk-automation build`로 첫 컴파일 비용을 분리한다.
3. DB에서 방 ID를 찾고 요청마다 다른 operation_id와 구분 가능한 본문을 준비한다.
4. 기본 방식은 `prepare` → 기본 Computer Use의 AX 입력·전송 → `result`로 DB 확인한다.
5. 헬퍼 방식은 `kakaotalk_send` 한 번을 호출한다. 오류·미확인은 새 요청 ID로 재발송하지 않는다.
6. DB에서 요청별 정확한 본문과 본인 발신 기록이 한 건인지 확인하고, 같은 operation_id 재호출 시 추가 전송이 없는지 확인한다.

실측 원본 지표는 같은 폴더의 JSON에 있다. 개인 방 ID·계정 ID·대화 본문은 포함하지 않았다.
